# Tablatura

Editor minimalista de tablaturas de violão, feito com Next.js e TypeScript.

## Rodar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Uso

No editor, clique em uma posição da tablatura e digite uma casa (0–99) ou `x`. Use as setas, Tab e Enter para navegar. Selecione a duração na barra superior e use **Exportar PDF** para abrir o diálogo de impressão do navegador, escolhendo “Salvar como PDF”.
